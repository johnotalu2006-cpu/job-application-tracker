# job-application-tracker
A Python-based job application tracker that records company names, job titles, application dates, and application statuses, with persistent JSON storage.

## About the Project

Keeping track of multiple job applications can become difficult.
This project provides a simple way to record applications, view
saved records, and monitor application statuses.

## Features

- Add new job applications.
- Record company names and job titles.
- Automatically record the application date.
- Track application status.
- View all saved applications.
- Store records persistently in a JSON file.
- Validate required company and job title fields.

## Technologies Used

- Python
- JSON
- pathlib
- datetime

## Requirements

- Python 3.10 or later recommended.
